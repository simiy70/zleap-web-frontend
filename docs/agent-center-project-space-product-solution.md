# Zleap Agent 中心与项目空间产品方案

## 1. 产品定位

本次重构使用两种不同的产品心智：

- **Agent 中心围绕“联系人”组织。** 用户像联系一位同事一样找到 Agent、发送消息、查看动态、管理自动化任务和检查能力配置。
- **项目围绕“共享空间”组织。** 项目用于集中保存项目说明、群聊、Agent、成员、资料和 Tools，不承担任务管理、项目阶段或进度看板职能。

“雇佣、创建、关注、官方”是 Agent 的关系或身份标签，不作为四个并列的首页入口。

## 2. Agent 中心

### 2.1 中心导航

Agent 中心包含四个轻量入口：

1. **消息**：最近 Agent 对话，默认入口。
2. **通讯录**：全部关联 Agent，一个 Agent 只出现一次，多重关系以标签展示。
3. **自动化**：汇总所有单 Agent 自动化任务。
4. **发现**：浏览并添加官方 Agent。

### 2.2 Agent 页面

打开 Agent 后，在内容顶部切换：

- 消息
- 动态
- 自动化任务
- 能力配置

Agent 身份、来源、状态和更多操作始终固定显示。

### 2.3 会话规则

Agent 数据必须显式声明 `sessionMode`：

| Agent 来源 | sessionMode | 会话行为 |
| --- | --- | --- |
| Zleap 创建、模板创建、官方添加 | `single` | 只有一个持续会话，不显示历史会话管理 |
| 本地接入 | `multiple` | 显示多个本地历史会话，默认打开最近活跃会话 |

系统 Agent 不提供新建、重命名、归档和删除会话入口。本地 Agent 可以管理多个会话。

### 2.4 自动化任务

自动化任务只使用两个状态：

- 正常执行：`enabled = true`
- 暂停：`enabled = false`

触发方式可以是定时、事件或手动，但不会增加草稿、执行中、待确认、成功、失败、结束等状态。

用户既可以在 Agent 的自动化任务 Tab 中创建任务，也可以在消息中用自然语言布置；消息确认后写入同一个任务集合。

全局自动化总览按 Agent 和状态筛选。点击任务时打开对应 Agent，并定位到自动化任务 Tab。项目空间不产生任务，因此不会与项目数据混合。

### 2.5 能力配置

能力配置包括：

- Skills
- Tools
- 信息源
- 角色与提示词
- 经验记忆
- 权限与通知

Agent 所有者可以编辑完整配置。普通使用者仅能调整自己的 Tools 和信息源授权。

## 3. 项目空间

### 3.1 创建

创建项目时只填写项目名称。创建后系统自动：

- 将项目设为私密；
- 将当前用户设为负责人；
- 创建空的项目说明；
- 创建“项目总群”；
- 进入空间概览。

Agent、成员、资料、Tools 和项目说明均允许创建后补充。

### 3.2 空间导航

项目空间包含：

- 概览
- 群聊
- Agent
- 资料
- 设置

项目内不提供项目阶段、本周重点、完成率、会话任务或项目任务看板。

### 3.3 空间概览

概览只表达空间中已经存在的内容：

- 项目说明（界面文案使用“项目说明”，内部结构可以表示为 `project.md`）
- 项目 Agent
- 项目成员
- 项目资料
- 最近群聊

空状态直接提供对应的添加或编辑入口，不显示进度指标。

### 3.4 群聊

项目支持一个“项目总群”和多个后续群聊。群聊支持：

- 多个人类成员；
- 一个或多个 Agent；
- `@Agent`；
- 引用项目资料；
- 明确展示 Agent 身份和项目角色。

群聊不提供消息转任务，也不产生会话任务。需要长期重复执行的工作仍由单 Agent 自动化任务承担。

### 3.5 项目 Agent 与资源边界

Agent 加入项目后：

- 继续使用自身 Skills；
- 只使用项目授权的 Tools；
- 只读取项目授权的资料；
- 不读取单 Agent 私聊；
- 不带入单 Agent 自动化任务；
- 不自动带入个人私有信息源。

移除项目资料后，后续 Agent 不再读取该资料，历史消息仍然保留。

## 4. 原型技术边界

- 数据仅保存在当前 React 会话中，刷新后恢复演示数据。
- 不连接真实 Agent、设备、授权、任务调度或后端接口。
- 所有创建、对话、任务启停、项目配置和资料操作均为高保真前端演示。
- 继续使用现有橙色品牌、玻璃质感、圆角卡片、顶部栏和底部 Dock。

## 5. 验收要点

- 系统 Agent 只有单一持续会话，本地 Agent 可以切换多个会话。
- 单 Agent 页面具备消息、动态、自动化任务和能力配置四个 Tab。
- 自动化任务只出现正常执行和暂停。
- 全局自动化总览可跳转到对应 Agent 的任务 Tab。
- 项目创建弹窗只有项目名称。
- 项目概览只展示说明、Agent、成员、资料和最近群聊。
- 项目群聊不存在会话任务或消息转任务入口。
- 项目 Agent 只能访问项目授权的 Tools 与资料。
