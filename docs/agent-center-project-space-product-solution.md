# Zleap Agent 会话与项目协作产品方案

## 1. 产品心智

- **Agent 是联系人。** 打开即对话，动态、自动化任务和能力配置是这个 Agent 的个人页签。
- **项目是协作空间。** 打开即进入协作现场，群聊和当前工作同时可见；完整看板与资料是另外两个工作区域。
- 页面直接呈现列表、聊天、看板和资料，不长期展示功能解释。权限规则放入按钮状态、Tooltip 和设置抽屉。

## 2. Agent

### 2.1 中心与个人页

中心保留消息、通讯录、自动化、发现四个入口。Agent 个人页保留消息、动态、自动化任务、能力配置四个 Tab，默认进入消息。

Agent 在通讯录、消息列表、标题和任务归属处都展示同一套头像、名称、在线状态与来源身份。本地接入 Agent 统一展示「本地」徽标。

通讯录使用官方、我创建的、本地和关注中四类筛选。卡片字段按类型变化：官方 Agent 突出服务 Skills，我创建的 Agent 展示 Skills、Tools 和自动化数量，本地 Agent 展示设备、历史会话和本地 Tools，关注 Agent 展示动态关系。

“发现”入口内部采用拟人化招聘与合作心智，展示岗位方向、官方认证、Skills、Tools 和可用状态。尚未建立关系的 Agent 使用“雇佣 Agent”，已加入联系人后使用“去对话”。

### 2.2 会话模型

| 来源 | `sessionMode` | 行为 |
| --- | --- | --- |
| Zleap 创建、模板创建、官方添加 | `single` | 单一持续会话，不出现历史会话入口 |
| 本地接入 | `multiple` | 右上角提供历史会话弹层，默认打开最近会话 |

本地会话弹层支持搜索、新建、切换、重命名、归档和删除。会话按 `updatedAt` 倒序显示，当前会话使用橙色选中态。数据使用 `archived` 标记归档状态。

### 2.3 引导式自动化

自动化任务只使用 `enabled: boolean`：

- `true`：正常执行
- `false`：暂停

全局自动化使用 Agent 名称输入搜索，不使用长下拉列表。从单 Agent 或全局自动化入口创建时，先进入对应 Agent 的消息：

1. Agent 询问持续目标。
2. 用户用自然语言回答。
3. Agent 生成包含名称、触发条件和推送位置的 `AutomationDraft` 确认卡。
4. 用户确认后生成 `AutomationTask`，默认正常执行。

取消或未确认的配置不会产生任务。项目工作项不进入自动化总览。

## 3. 项目空间

### 3.1 创建与导航

创建项目只填写项目名称。系统默认创建私密项目、设置当前用户为负责人并生成“项目总群”，完成后直接进入会话页。

项目顶部只保留三个同级区域：

- **会话**：默认入口，包含项目群聊与多个独立对话。
- **自动化任务**：管理只在当前项目范围内运行的自动化。
- **项目概况**：集中展示项目配置、协作者、权限、项目动态与产出。

项目列表与创建项目空间位于项目详情之外。权限、通知、归档和删除等低频操作继续收进设置或更多菜单。

### 3.2 会话

会话页左侧按关系拆分为：

- **项目群聊**：项目总群及后续创建的多人群聊。
- **独立对话**：用户与某个项目 Agent 的项目内独立会话。

中间区域展示当前会话与消息输入，宽屏右侧补充会话成员和已共享项目资料。独立对话仍受项目授权边界约束，不带入该 Agent 的个人私聊、个人信息源或单 Agent 自动化任务。

### 3.3 项目自动化任务

项目自动化任务由项目 Agent 执行，可以把结果发送到项目总群、项目资料或仅通知负责人。状态继续只使用：

- 正常执行：`enabled = true`
- 暂停：`enabled = false`

项目自动化与单 Agent 自动化使用不同归属字段，不进入 Agent 中心的全局自动化总览。

### 3.4 项目概况与能力边界

项目概况作为同级 Tab，包含：

- **项目配置**：`project.md`、技能、项目资料/信息源和工具。
- **协作者**：项目 Agent 与成员。
- **权限**：可见范围、邀请制和负责人。
- **项目动态**：配置、协作与产出事件。
- **产出**：由成员或 Agent 沉淀的项目成果。

`effectiveSkills` 从项目 Agent 的 Skills 聚合；`effectiveTools` 是 Agent Tools 与项目授权 Tools 的交集；项目资料和信息源只包含项目明确授权内容。添加或移除 Agent 后，技能与工具范围即时同步。

## 4. 原型边界与验收

- 数据继续使用 React 会话状态模拟，不连接真实后端。
- Agent 头像在全部页面保持圆形。
- 系统 Agent 没有会话管理入口，本地 Agent 可以管理多个历史会话。
- 自动化创建在消息内完成，确认前不写入任务。
- 项目创建完成后进入项目总群。
- 会话页同时支持项目群聊和多个项目内独立对话。
- 项目自动化可以创建、筛选、启停并选择结果位置。
- 项目顶层仅有会话、自动化任务、项目概况。
- 项目概况能随 Agent、Tools 和信息源授权变化即时更新。
- 主页面不出现重复的模块介绍文案，只保留用户内容、必要状态、空状态、错误和确认信息。
