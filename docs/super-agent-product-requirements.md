# Zleap Web Super Agent 产品规则

本文是 Web 原型中 Super Agent 的本地权威说明，对应飞书《SuperAgent-需求文档》v1.12.0。实现继续使用 React 会话状态模拟，不连接真实后端。

## 1. 对象与入口

- 系统为当前用户准备且只准备一个 Super Agent。该对象不可删除，权限固定为「私密」，可修改名称、头像和角色提示词。
- 悬浮头像展示在桌面、Feed、信息源列表与内容详情、普通 Agent 详情；在 Super Agent 消息详情、项目、成员管理和配置弹窗中隐藏。
- 存在任一未读消息时头像展示红点，不展示数量。打开悬浮会话、进入 Super Agent 详情或打开日报卡片均将消息置为已读。
- 悬浮会话和消息详情共用消息、草稿、页面引用、推荐问题、新话题与自动化任务步骤。

## 2. 会话与上下文

- 消息按发送时间正序展示；有未读时定位首条未读，否则定位最新消息。
- 空会话展示欢迎语和当前页面引用；2—4 个推荐问题统一展示在最近一条 Agent 回复下方，输入区仅保留「开启新话题」。发送后立即出现「对方输入中」占位，回答就位后替换；失败保留原问题并提供重试。
- 「开启新话题」插入分割线和开场白；若线程末尾已经是尚未发言的新话题，不重复插入。
- 上下文只由系统识别，用户只能关闭。优先级为当前单对象详情，其次当前列表流；关闭后在本次悬浮窗打开期间保持关闭，重新打开后再次识别。
- 已发送消息保留发送时的上下文快照，不受后续页面切换影响。
- Agent 回答可带「N 条来源 · HH:mm」入口，在当前会话载体内打开来源 bottom-sheet；关闭后保留消息、草稿与引用。

## 3. 设置

- 基础设置：名称必填且为 1—20 个字符；头像可选系统头像或上传 PNG/JPG/WebP，原型限制为 2 MB。保存后同步所有入口。
- 角色定义：提示词必填且最多 20,000 字符，支持复刻现有 Agent、导入 `.md` 和一键完善；覆盖未保存内容前需确认。
- Super Agent 权限只读显示「私密」；普通自有 Agent 可选择私密、部分可见或所有人可见。
- 自动化任务默认按创建时间倒序，可按全部、启用中、已暂停筛选；支持查看、启停、删除、立即执行和推送配置。暂停与删除需要二次确认。

## 4. 自动化任务引导

任务引导状态依次为：意图识别、信息收集、材料选择、执行 Agent 选择、提交、成功或失败。

- 仅未来时间、重复周期或明确定时要求进入任务创建；立即需求直接回答，意图不明时追问。
- 必填信息包括任务名称、执行内容、执行时间、任务材料、执行 Agent 和启用状态。
- 材料支持多选，默认勾选推荐项；选择区停靠在当前会话底部并替换输入区。
- Super Agent 只能从当前用户管理的 Agent 中单选执行者，推荐项置顶且默认选中；普通 Agent 固定由自己执行并跳过该步骤。
- 确认最后一个选择后直接提交，不再展示创建前确认卡。成功后展示任务结果卡，失败后提供再次创建入口。

## 5. 默认日报

- 当前用户初始拥有一个已启用的「每日总结日报」系统默认任务，执行 Agent 为 Super Agent，执行时间为每天 09:00，材料为可访问的公共和个人信息源。
- 默认任务支持暂停、恢复、编辑、删除和立即执行；删除后本次原型会话内不自动重建。
- 日报成功后以报告分享卡片推送并计入未读；失败不推送也不计入未读。卡片展示封面、含日期标题和摘要，点击进入报告详情。

## 6. 原型异常约定

- 请求处理中禁止重复提交；失败时保留输入和选择，并提供重试。
- 无权限或失效上下文不读取具体内容，显示原因后回退为普通问答。
- 在会话中发送「加载失败」可复现回答失败；发送「任务创建失败」可复现任务提交失败。
- 所有删除动作必须二次确认；未实现的后台编辑能力明确提示「demo 暂未实现」。
