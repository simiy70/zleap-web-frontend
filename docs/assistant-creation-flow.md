# Zleap 助手创建与外部 Agent 接入流程

## 产品目标

用户从助手管理页的统一入口完成两类任务：

1. 通过提示词、`AGENTS.md` 或系统模板创建 Zleap 助手。
2. 将设备中已经识别的本地 Agent 复制导入 Zleap。

创建阶段只收集完成创建所需的最少输入。头像、名称、简介、权限和关联信息源由系统生成，用户可在创建后进入助手详情调整。

## 创建入口

顶部「创建助手」按钮与管理列表中的新建卡片均打开锚定式下拉菜单：

- **创建 Zleap 助手**
- **接入外部 Agent**

入口只负责选择路径。两条创建路径都在助手管理页上方以大尺寸弹窗展开，不跳转二级页面；助手列表始终保留在背景中。

## 创建 Zleap 助手

### 手动创建

用户输入助手用途或提示词，可通过「一键完善」预览优化版本。只有用户点击「采用优化」后才替换原内容。

### 导入文件

- 支持任意 `.md` 文件，界面推荐使用 `AGENTS.md` 命名，但不限制具体文件名。
- 文件不能超过 1MB。
- 首个 Markdown 标题作为名称，首段正文作为简介，完整文件作为提示词。
- 文件名不匹配、内容为空、文件超限或读取失败时展示具体原因。

### 系统模板

首期提供研发、知识管理和研究分析三个类别共六个模板。选择模板后直接生成助手。

### 创建结果

系统生成完成后直接创建助手，并展示结果卡片：

- 头像
- 名称
- 简介
- 可见权限
- 已关联公共信息源数量
- 编辑详情入口

结果卡片代表创建已经完成，不再增加确认创建步骤。

## 默认权限与信息源

所有新建和导入的助手统一使用以下默认值：

- 权限为 `mine`，即「私密」，仅自己及管理员可见。
- `visibleTargets` 为空。
- 自动关联当前用户可访问的全部 `enterprise` 信息源，即「所有人可见」的公共信息源。

助手可见权限与信息源权限相互独立：

- 助手权限控制谁能看到和使用助手。
- 信息源权限控制创建者能否将该信息源关联给助手。
- 私密助手可以使用公共信息源。
- 用户不能关联自己无访问权限的信息源。

## 助手详情

助手结果卡片和助手卡片更多菜单均可进入详情页。

详情页支持：

- 修改头像、名称和简介。
- 修改可见权限。
- 增删关联信息源。
- 在折叠的高级设置中查看、修改和完善提示词。

权限与信息源保持相同的三档模型：

| 值 | 名称 | 含义 |
| --- | --- | --- |
| `mine` | 私密 | 仅自己及管理员可见 |
| `partial` | 部分可见 | 指定人员或部门可见 |
| `enterprise` | 所有人可见 | 企业内所有人可见 |

选择「部分可见」时必须至少选择一个部门或成员。人员与部门支持搜索、选择和标签移除。

关联信息源列表展示权限徽章。全部公共信息源默认选中；用户可以移除公共信息源，或添加自己有权访问的私密、部分可见信息源。

## 接入外部 Agent

进入接入弹窗后，第一步展示一次性终端连接指令：

- 用户复制指令并在终端运行。
- 指令只扫描支持工具的标准 Agent 配置目录，不读取对话内容和无关文件。
- 复制后页面进入实时等待状态。
- 系统检测到设备响应后自动进入 Agent 选择，不需要「我已运行」或「开始检测」按钮。

连接成功后，系统实时加载设备中的 Agent 状态：

- 加载期间展示短暂骨架屏。
- 列表自动展示来源、路径、更新时间和兼容状态。
- 首期演示 Codex、Claude Code 和 Cursor。

用户可以多选：

- 可兼容 Agent 可直接导入。
- 需调整 Agent 可选择，同时展示能力差异。
- 不兼容 Agent 禁止选择。
- 同名助手使用来源后缀创建副本，不覆盖已有助手。

首期采用复制导入，导入后不与本地文件持续同步。外部 Agent 同样默认私密，并关联全部公共信息源。

## 信息源连接指令

外部 Agent 导入完成后，结果页默认勾选：

> 向已接入 Agent 发送 Zleap 信息源连接指令

用户确认后：

1. 为每个导入的 Agent 创建独立会话。
2. 根据该助手实际关联的信息源生成连接指令。
3. 将指令作为用户发送的消息写入对应会话。
4. 自动进入第一个导入 Agent 的对话。

其他 Agent 的指令保留在各自会话中。界面只回显「已发送」，不模拟外部 Agent 已经配置成功。

## 首期技术边界

- 数据仅保存在当前 React 会话中，刷新后重置。
- AI 完善、设备状态和连接指令均为高保真前端演示。
- 不接真实 AI、设备扫描、MCP 服务或后端接口。
- 不实现本地 Agent 配置持续同步。

## 验收标准

- 两个创建入口均显示相同的路径下拉菜单。
- 三种 Zleap 创建方式都能生成助手结果卡片。
- 所有新助手默认私密并关联全部公共信息源。
- 部分可见未选择部门或成员时不能保存。
- 无权限信息源不能选择。
- 详情保存会同步更新助手卡片和对应会话名称。
- 外部 Agent 列表无需手动触发即可加载。
- 连接指令会写入每个外部 Agent 的独立会话。
- 普通对话输入可以发送并回显为用户消息。
